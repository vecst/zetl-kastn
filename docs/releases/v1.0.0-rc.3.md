# Zetl 1.0.0 RC 3

A larger candidate: pass-through replaces Pop, Kastn has been rebuilt inside
for speed and safer editing, and Zetl uses much less memory. If you're on RC 2
or 2.1, replace both `Zetl.exe` and `Kastn.exe`; your notes and settings carry
over.

Download `Zetl-v1.0.0-rc.3-win-x64.zip`, extract it, and run `Zetl.exe`. It's
not yet code-signed, so Windows may show a SmartScreen warning: choose **More
info → Run anyway**.

## Upgrading

- **Pop is now pass-through, and held `Ctrl+P` means something new.** The
  per-bucket Pop switch is gone. Pass-through is one setting, off by default:
  turn it on in **Settings**, or hold `Ctrl+P` to flip it for a while. Any
  "Pop Review" buckets you already have stay as they are.
- **The second lane is called Shift** by default (it was "Alternate"). A lane
  name you set yourself is kept.
- **If you started on RC 1,** the guided tour opens once. RC 1's old help window
  wasn't the real introduction.

## New

- **Pass-through.** While a project is collecting your copies, a copy you paste
  straight away (a link for a friend, a number for a form) was only passing
  through, so it doesn't stay in your project. It moves to the project's
  **Passed Through** bucket instead, and holding `Ctrl+Z` brings it back.
  - Only copies Zetl collected on its own pass through. A held `Ctrl+C` capture
    or a quick note never does, and neither does an older copy.
  - A held `Ctrl+P` flips it for the current lane (`Ctrl+Shift+P` for the Shift
    lane). It flips back after 10 minutes without a copy or paste, or when you
    switch projects, and the tray icon turns orange while it's flipped on.

## Changed

- **Kastn is much faster on large projects.** The tree, reader, Board, and
  inspector only draw what's on screen. Pictures load in the background, and
  how many stay in memory is capped.
- **Zetl uses far less memory.** It now draws its popups and hold ring in
  software on Windows, without slowing popups down compared with RC 2.1.
- **Measuring your taps and holds suggests a threshold that feels deliberate.**
  It no longer lets one early release or quick drummed taps pull the hold time
  down to a twitchy 200 ms or so.
- **The tray menu opens quickly the first time** you right-click it.
- **The Shift Board opens on the Shift Journal** when no Shift project is
  active, instead of whichever project was written last in either lane.

## Fixed

- **Quitting Zetl twice while Kastn asks about unsaved changes** could close
  Zetl under Kastn's dialog, after which Kastn started a new Zetl. A second Quit
  now waits for your answer in Kastn.
- **Kastn kept edits more reliably:** while a save, a move, formatting, a link,
  or a picture change was still in flight, and when you navigated away mid-edit.
  Selecting across buckets during autosave no longer jumps back.
- **The tour's cut step** now finishes when you press `Esc` and the sentence
  comes back, and going back to a step you've done no longer asks you to repeat
  it.
- **Kastn's tree** keeps its drag feedback across nested buckets and no longer
  leaves stale drop highlights.
- **Exported PDFs** keep task checkboxes clickable.
- **Kastn's app icon** shows correctly.
